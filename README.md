# Something Doesn't Fit

The working vault for the novel *Something Doesn't Fit* (Spanish: *Algo No Encaja*). It is an Obsidian vault: manuscript, structure, characters, research and the site that maps the book.

## Read it as a website: the Atlas

**https://claude.ai/artifact/57zHit7EYNwWhgZiVBm9q7**

The Atlas is the whole book on one page: every chapter with its beats, the journey, the structure, the mind map, the reveals, a pinboard, and the conspiracy-engines library. Every chapter, proposal and open decision has a note box, and the notes save with the page. It is private, so it opens only for Santi, signed in to claude.ai.

How the page is built, and where its notes are stored, is in [10 Site/README.md](10%20Site/README.md).
